# Cisco Packet Tracer – 10 Router Network

This project contains a **10-router network topology designed using Cisco Packet Tracer**. It demonstrates IP addressing, routing, router configuration.

## Key Features

* 10 Cisco routers
* Network topology design
* IP addressing
* Router configuration
  
## Tool Used

* Cisco Packet Tracer

## Project Objective

The main objective of this project is to understand and practically demonstrate how multiple routers communicate with each other and how routing is used to connect different networks.
